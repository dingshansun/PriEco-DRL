# Scenario data attribution and licensing

The Amsterdam corridor network and stop geometry incorporate OpenStreetMap-derived geographical data, edited for this research scenario.

Map data: **Copyright OpenStreetMap contributors**. OpenStreetMap data is available under the **Open Data Commons Open Database License (ODbL) 1.0**:

- Attribution and source: https://www.openstreetmap.org/copyright
- License: https://opendatacommons.org/licenses/odbl/1-0/

The distributed scenario input bundle comprises the six SUMO configuration/XML files and seven text metadata files listed in the README. It is supplied as OpenStreetMap-derived research scenario data under ODbL 1.0, including the authors' scenario edits and associated input tables. Its data rights are separate from the MIT-licensed Python implementation and original documentation. The MIT License does not replace the OpenStreetMap data license.

The XML generator comments retain their tool/version information. Two local filesystem paths in the network's generator comment have been replaced by the relative network filename; active simulation elements and attributes are unchanged.
